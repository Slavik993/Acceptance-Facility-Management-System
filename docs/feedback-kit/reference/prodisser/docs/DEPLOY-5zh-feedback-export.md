## 5ж. Замечания для исполнителя правок: выгрузка по ключу

Замечания с кнопки (Р-403) разбирает руководитель на экране «Замечания».
Исполнитель правок — Claude Code в облачной среде — учётной записи в
кабинете не имеет; ему открыт отдельный вход по ключу (решение Р-405):

- `GET /api/feedback/export[?status=NEW,IN_WORK]` — перечень замечаний,
  свежие сверху, со временем по Москве, местом, устройством, текстом и
  разбором;
- `GET /api/feedback/export/<id>/screenshot` — снимок экрана к замечанию;
- `PATCH /api/feedback/export/<id>` с `{status?, severity?, note?}` —
  разбор, как на экране «Замечания».

Ключ открывает только замечания: ни заявок, ни кабинета, ни файлов работ.
Без ключа на сервере адреса нет (ответ 404), неверный ключ отвечает так же.

### Настройка — один раз

**1. Ключ на сервере** (под `root`). Создаётся здесь же и в переписку не
попадает:

```bash
cd /opt/prodisser/deploy
echo "FEEDBACK_EXPORT_TOKEN=$(openssl rand -hex 32)" >> .env
docker compose --env-file .env -f docker-compose.yml up -d web
grep '^FEEDBACK_EXPORT_TOKEN=' .env    # строку после «=» — в шаг 2
```

**2. Тот же ключ в облачной среде Claude Code**: меню среды в заголовке
сеанса → Edit → переменная окружения `FEEDBACK_EXPORT_TOKEN`. Там же,
Network access → Custom: добавить `prodisser.ru`, список менеджеров пакетов
по умолчанию оставить. Значения подхватывает новый сеанс.

**3. Проверка.** Строка отчёта цепочки в журнале выката (раздел 5г, запуск
кнопкой): «замечания: выгрузка для правок включена». «Ключ задан в .env, но
приложение его не видит» — не выполнена команда `up -d web` из шага 1.

### Как пользоваться

```bash
NODE_USE_ENV_PROXY=1 node tools/feedback-pull.mjs --open        # открытые
NODE_USE_ENV_PROXY=1 node tools/feedback-pull.mjs               # все
NODE_USE_ENV_PROXY=1 node tools/feedback-pull.mjs review <id> status=FIXED note="что сделано"
```

Выгрузка складывается в `feedback-export/` (в `.gitignore`): `feedback.json`
и снимки. Каждая выгрузка и каждый разбор по ключу пишутся в журнал
кабинета действующим лицом «система» с пометкой `via: key`.

**Сменить ключ** — заменить строку в `.env`, повторить `up -d web` и
переменную в среде. **Закрыть вход** — удалить строку и выполнить
`up -d web`.
