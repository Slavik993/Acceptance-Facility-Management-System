# Пакет «Кнопка замечаний»: из ProDisser в «Приёмку»

Пакет переносит в кабинет «Приёмки» (DOLGIY STUDIO) механизм ProDisser:

- кнопка в углу экрана для замечаний, рекомендаций, комментариев и отметок
  «работает верно»;
- автоматический сбор в таблицу;
- разбор руководителем;
- книга Excel;
- выгрузка для исполнителя правок по ключу.

## Состав

| Файл | Назначение |
|---|---|
| `PROMPT.md` | Промпт: первое сообщение новому сеансу Claude Code на репозитории «Приёмки» |
| `SPEC.md` | Техническое задание: как устроено в ProDisser, что и как делается в «Приёмке», проверки, критерии приёмки |
| `templates/packages/domain/src/feedback.ts`, `feedback.test.ts` | Правила замечаний: виды, шаблон адреса экрана, устройство, контакты в тексте, критичность, разбор отправки. 23 теста |
| `templates/packages/importer/src/feedback-book.ts`, `feedback-book.test.ts` | Книга Excel: листы «Замечания» (17 столбцов) и «Сводка». 6 тестов |
| `templates/scripts/feedback-pull.mjs` | Утилита исполнителя: перечень и снимки, книга, разбор |
| `reference/prodisser/` | Исходники работающего механизма ProDisser (коммит `f702268`) и выдержки решений Р-403, Р-405, Р-583 |

Заготовки проверены на копии «Приёмки» (`main` `053cd2c`):

- тесты — 29 из 29;
- `tsc` и `eslint` — без замечаний;
- утилита — на заглушке сервера.

## Запуск

1. Положить папку `feedback-kit` в репозиторий «Приёмки» в
   `docs/feedback-kit/`. Например, через GitHub: Add file → Upload files,
   в новую ветку. Другой путь — приложить `feedback-kit.zip` к первому
   сообщению сеанса.
2. Открыть сеанс Claude Code на репозитории «Приёмки». Первым сообщением
   вставить текст `PROMPT.md` ниже черты.
3. Проверить запрос на слияние и дать согласие на слияние и выкат.

## После выката

- Ключ исполнителя — SPEC §12: строки `FEEDBACK_EXPORT_TOKEN` и
  `FEEDBACK_EXPORT_ORG` в `.env` сервера; та же строка и адрес стенда — в
  среде Claude Code.
- Демонстрация — переменная репозитория `FEEDBACK_URL` с адресом
  приёмника Apps Script (`12_FEEDBACK.md`), если она ещё не задана.
- Еженедельный разбор — SPEC §9.
